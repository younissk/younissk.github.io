The public site for Basira, built on the AstroWind template and then taken well past it: MDX
content, a Decap CMS admin mounted from `public/`, a p5.js particle-network hero, and a build that
ships as a Docker image behind nginx with its own compose file and CI workflow.

This is the fourth and current attempt at the Basira site. It replaces `basira-nextra` (a Nextra
docs template), `basira-website` (an Eleventy + Netlify CMS starter) and `Basira.tech`.
