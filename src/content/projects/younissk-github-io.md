A hand-written static site — no framework, no build step — using Tailwind's browser build and a set of small vanilla-JS controllers: an animated CRT/scanline background, a navigation controller, section containers, and a data loader that renders the education, ML/AI and web-dev sections from JSON files rather than hard-coded markup.

This is the surviving one of several attempts at a personal site. The others were `final-final-portfolio-hopefully` (a much larger Docusaurus build with docs and posts), `portfolio` (a three-file HTML sketch) and `showcase` (an early `<details>`-based list of client work).
