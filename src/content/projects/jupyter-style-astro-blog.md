A reusable starter built on Astro's blog template, restyled so posts read like notebook cells. Theming is centralised in `consts.ts` and `theme.ts` so a fork can rebrand without touching components, and Recharts is included for posts that need charts inline.

It was written to be handed to other people, not just used once — the README keeps a showcase list of sites built from it, and it is the template behind a 100 Days of AI blog.
