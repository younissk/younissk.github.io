The student-facing web platform for Tasis al-Ilm: courses split into sections and lessons, a lesson
sidebar with next/previous navigation, an installable PWA manifest, an admin-only route tree, and
paid access through PayPal subscriptions.

Content is served from a companion Strapi backend (`tasis-al-ilm-strapi`), which holds the CMS
configuration, upload pipeline and plugin setup for the same product.
